interface FunnelDataPoint {
  date: string;           // YYYY-MM-DD
  impressions: number;
  storeVisits: number;

  uninstalls: number;
  activeUsersWeekly: number;

# 05 — Review Intelligence

## Goal

Transform reviews from "read and react emotionally" into structured, actionable intelligence. Cluster reviews into categories, track sentiment trends, and surface the top issues with evidence.

## Context

The existing app already scrapes reviews via `/api/scrape`. This prompt adds analysis depth and a new UI. The existing `ReviewsTab.tsx` is deprecated in favor of the new `ReviewsPage.tsx`.

## Requirements

### 1. Review Analysis Pipeline

`server/analysis/reviewIntelligence.ts`

Input: array of scraped reviews (text, rating, date, author).

Processing steps:
1. **Sentiment classification** — Classify each review as positive, negative, neutral, or mixed. Use a simple heuristic first (rating-based: 1-2 negative, 3 neutral, 4-5 positive) with keyword overrides (e.g., "but" in a 5-star review → mixed).

2. **Topic extraction** — Extract key topics/themes from each review. Use one of:
   - LLM-based: send batches of 20 reviews to the existing AI endpoint with a structured prompt that returns topics per review
   - Rule-based fallback: keyword matching against predefined categories

3. **Clustering** — Group reviews into actionable buckets:
   - `onboarding` — setup, installation, getting started, confusing
   - `performance` — slow, laggy, memory, CPU, crashes
   - `missing_feature` — wish, would be nice, doesn't support, need
   - `bugs` — broken, doesn't work, error, bug
   - `pricing` — expensive, free, price, worth
   - `ux` — confusing, hard to use, intuitive, design
   - `other` — uncategorized

   Each review can belong to multiple clusters. Store the mapping.

4. **Impact scoring** — For each cluster, compute:
   - Review count in cluster
   - Average rating of reviews in cluster
   - Recency weight (recent reviews scored higher)
   - Impact score = f(count, avg_rating_gap, recency)

5. **Trend detection** — For each cluster, detect if volume is increasing, stable, or decreasing over the last 90 days.

Output type:
```typescript
interface ReviewIntelligence {
  summary: {
    totalReviews: number;
    averageRating: number;
    sentimentDistribution: { positive: number; negative: number; neutral: number; mixed: number };
    ratingDistribution: Record<1 | 2 | 3 | 4 | 5, number>;
  };
  clusters: ReviewCluster[];
  trendAlerts: TrendAlert[];      // clusters with increasing negative volume
  topIssues: TopIssue[];          // top 3 actionable items
}

interface ReviewCluster {
  id: string;
  label: string;
  count: number;
  averageRating: number;
  impactScore: number;           // 0-100
  trend: 'increasing' | 'stable' | 'decreasing';
  exampleReviews: Array<{ text: string; rating: number; date: string }>;  // top 3 representative
}

interface TopIssue {
  rank: number;
  cluster: string;
  summary: string;              // one-sentence AI-generated summary
  evidenceCount: number;
  suggestedAction: string;      // one-sentence suggestion
}
```

### 2. Backend Routes

- `POST /api/reviews/analyze` — Takes extension ID or scraped reviews, runs the pipeline, returns `ReviewIntelligence`

# 06 — Listing Health Score v2 (Explainable & Evidence-Traced)

## Goal

Rebuild the existing listing score to be fully explainable: every score point links to a specific data point, and every recommendation cites its evidence. Users should never ask "why did I get this score?"

## Context

The existing app has scoring logic in `server/analysis/*` and displays it in `ScoreCard.tsx` / `IssuesTab.tsx`. This prompt replaces the display and enriches the backend scoring with evidence tracing. Keep the existing scoring dimensions and ADD new ones — do not remove any existing score calculations.

## Requirements

### 1. Scoring Dimensions

Retain existing dimensions and add these new ones. Each dimension has a weight, a score (0-100), and an array of evidence items.

```typescript
interface ScoringDimension {
  id: string;
  label: string;
  weight: number;           // 0-1, all weights sum to 1
  score: number;            // 0-100
  maxScore: number;         // always 100
  evidence: EvidenceItem[];
  suggestions: Suggestion[];
}

interface EvidenceItem {
  type: 'positive' | 'negative' | 'neutral';
  description: string;      // e.g., "Description contains 1,240 characters"
  impact: number;           // how much this item affects the score (-30 to +30)
  source: string;           // where the data came from: 'listing', 'reviews', 'benchmarks', 'permissions'
}

interface Suggestion {
  priority: 'high' | 'medium' | 'low';
  action: string;           // what to do
  reasoning: string;        // why (references evidence)
  estimatedImpact: string;  // e.g., "Could improve install rate by ~5-15%"
}
```
